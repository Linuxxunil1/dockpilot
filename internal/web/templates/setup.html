Wie soll dieser dockpilot-Server betrieben werden?

Zugangsdaten festlegen

Wähle einen Benutzernamen und ein sicheres Passwort für den Login.

✓

Setup abgeschlossen

Zugangsdaten gespeichert. Du kannst dich jetzt einloggen.

Zum Login →

Hub-Verbindung einrichten

Gib die URL des Hub-Servers und den dort generierten Token ein.
Den Token erhältst du auf dem Hub unter Server → Agent einladen.

🔌

Agent eingerichtet

Dieser Server verbindet sich jetzt mit dem Hub.
Das vollständige Dashboard ist auf dem Hub-Server verfügbar.

Nächste Schritte auf dem Hub:
  1. Hub-Dashboard öffnen → Tab Server
  2. Agent einladen klicken, denselben Token eingeben
  3. Agent erscheint nach dem ersten Verbindungsversuch (bis zu 30 Sek.)
Fertig →
