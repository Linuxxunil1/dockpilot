Installationsmodus

Wie soll dieser dockpilot-Server betrieben werden?

🖥️
Standalone
Einzelserver — verwalte nur diesen Host. Die einfachste Installation.
🌐
Hub (Hauptserver)
Zentrales Dashboard — verwalte diesen und weitere Remote-Server.
🔌
Agent (Client)
Wird vom Hub gesteuert — kein eigenes Dashboard, verbindet sich automatisch.

Zugangsdaten festlegen

Wähle einen Benutzernamen und ein sicheres Passwort für den Login.

mTLS-Zertifikat optional

Schütze deinen Zugang mit einem Browser-Zertifikat. Ohne gültiges Zertifikat kommt niemand zur Login-Seite — auch mit gestohlenen Zugangsdaten nicht.

Zertifikat erstellt — alles herunterladen:
P12-Passwort:
↓ client.p12 ↓ ca.crt
⬆ client.p12 herunterladen um fortzufahren
Nächste Schritte:
1. client.p12 im Browser / OS importieren
2. ca.crt in deinen Reverse Proxy (nginx, Caddy …) einbinden und Client-Auth aktivieren
Diesen Schritt überspringen
✓

Setup abgeschlossen

Zugangsdaten gespeichert. Du kannst dich jetzt einloggen.

Hub-Verbindung einrichten

Gib die URL des Hub-Servers und den dort generierten Token ein.
Den Token erhältst du auf dem Hub unter Server → Agent einladen.

🔌

Agent eingerichtet

Dieser Server verbindet sich jetzt mit dem Hub.
Das vollständige Dashboard ist auf dem Hub-Server verfügbar.

Nächste Schritte auf dem Hub:
  1. Hub-Dashboard öffnen → Tab Server
  2. Agent einladen klicken, denselben Token eingeben
  3. Agent erscheint nach dem ersten Verbindungsversuch (bis zu 30 Sek.)
